Política de Privacidade

Última atualização: 2026

1. Dados Coletados

Coletamos nome de usuário, tarefas cadastradas e dados necessários para autenticação.

2. Uso das Informações

Os dados são utilizados apenas para funcionamento do sistema.

3. Armazenamento

As informações são armazenadas de forma segura no servidor.

4. Compartilhamento

Não vendemos ou compartilhamos seus dados com terceiros.

5. Segurança

Utilizamos autenticação via token para proteger sua conta.

6. Direitos do Usuário

Você pode solicitar exclusão da conta a qualquer momento.
